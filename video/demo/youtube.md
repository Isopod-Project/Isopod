## Title

Isopod: self-hosted Minecraft servers, managed like Prism instances

## Description

Isopod is a free, open-source dashboard for running Minecraft servers in Docker. This demo creates a Fabric server, starts it, adds a mod from Modrinth with its dependencies, sends a command through the live console, and sets up world backups.

- Vanilla, Fabric, Forge, NeoForge and Quilt for mods; Paper, Purpur and Folia for plugins
- Bedrock Dedicated Server, plus Bedrock cross-play through Geyser and Floodgate
- Mod search on Modrinth with automatic dependency resolution
- Modpacks from Modrinth and CurseForge
- Live console with RCON commands
- Scheduled world backups and pre-update snapshots
- Crash watchdog with restart policies
